# 🏋️‍♀️ 健身打卡和饮食管理小程序

一个基于 uniapp 开发的健身打卡和饮食管理小程序，帮助用户记录运动数据、管理饮食摄入，实现健康生活目标。

## ✨ 功能特色

### 🏃‍♀️ 健身打卡

- **运动计时器**：支持跑步、健身、瑜伽、骑行等多种运动类型
- **实时统计**：显示运动时长、消耗卡路里、运动强度
- **目标管理**：设置每日运动目标，跟踪完成情况
- **历史记录**：查看运动历史，分析运动趋势

### 🥗 饮食管理

- **食物库**：丰富的食物数据库，包含卡路里信息
- **快速记录**：支持早餐、午餐、晚餐、加餐快速记录
- **营养分析**：分析营养均衡度和热量控制
- **饮食建议**：提供个性化饮食建议

### 📊 数据统计

- **今日概览**：显示今日运动、饮食数据
- **周统计**：本周运动天数、总消耗卡路里等
- **趋势分析**：运动趋势图表（可扩展）
- **成就系统**：运动徽章和成就奖励

### 👤 个人中心

- **用户信息**：个人资料管理
- **数据概览**：连续天数、总运动次数、减重数据
- **目标设置**：个性化目标配置
- **健康建议**：每日健康小贴士

## 🎨 设计特色

### 视觉设计

- **现代简约**：采用卡片式设计，界面简洁美观
- **渐变背景**：使用紫色渐变背景，营造科技感
- **健康色彩**：主色调为绿色，体现健康理念
- **响应式布局**：适配不同屏幕尺寸

### 交互设计

- **直观操作**：一键开始运动，快速记录饮食
- **实时反馈**：运动过程中实时显示数据
- **动画效果**：按钮点击、页面切换动画
- **用户引导**：清晰的操作提示和反馈

## 🛠️ 技术架构

### 前端技术

- **框架**：uniapp + Vue 3
- **样式**：SCSS + 响应式设计
- **组件化**：可复用的 UI 组件库
- **状态管理**：Vue 3 Composition API

### 数据存储

- **本地存储**：uni.storage 本地数据持久化
- **数据结构**：JSON 格式存储运动、饮食数据
- **数据管理**：封装 StorageManager 类统一管理

### 组件设计

- **UI 组件**：ui-card、ui-button、ui-progress
- **功能组件**：workout-timer、food-selector
- **业务组件**：common-nav-bar、自定义导航栏

## 🚀 快速开始

### 环境要求

- Node.js 14+
- HBuilderX 或 微信开发者工具
- uniapp 开发环境

### 安装运行

1. **克隆项目**

   ```bash
   git clone [项目地址]
   cd fitness-app
   ```

2. **安装依赖**

   ```bash
   pnpm install
   ```

3. **运行项目**
   - 使用 HBuilderX 打开项目
   - 点击"运行" → "运行到微信开发者工具"
   - 或直接导入 `unpackage/dist/dev/mp-weixin` 到微信开发者工具

### 开发指南

#### 添加新功能

1. **创建页面**：在 `pages/` 目录下创建新页面
2. **注册路由**：在 `pages.json` 中添加页面配置
3. **开发组件**：在 `components/` 目录下创建可复用组件
4. **数据管理**：使用 `utils/storage.js` 管理数据

#### 自定义样式

- 修改 `uni.scss` 全局样式变量
- 使用 SCSS 变量统一管理颜色、尺寸
- 遵循设计系统规范

#### 数据扩展

- 扩展 `FitnessDataManager` 类添加新功能
- 修改数据结构适配新需求
- 保持数据格式一致性
